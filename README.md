# 🤖 AI Blog Web App

A Flask-based blog application with AI-powered summaries.

## 🚀 Features
- Blog listing
- Search & pagination
- AI summary using OpenAI
- Caching system

## 🛠 Tech Stack
- Python
- Flask
- OpenAI API

## ⚙️ Setup

pip install -r requirements.txt

Create .env:
OPENAI_API_KEY=your_key

Run:
python app.py
